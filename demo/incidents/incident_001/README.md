# Demonstration Investigation (Real Data)

This incident uses real Sentinel-1 data and the DARTIS dataset.
- **Real Data**: Sentinel-1 VV/VH tiles, georeferencing via GCPs, DARTIS annotation reference.
- **Precomputed/Unavailable**: AIS and environmental drift data are unavailable for this historical demo.
- **Limitations**: Attribution system is investigative, not legal proof. The oil mask is a published reference, not an AI prediction.
