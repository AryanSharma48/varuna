# Published Reference Oil-Slick Annotation

DARTIS 2019 dataset (PANGAEA DOI: 10.1594/PANGAEA.980773)
Record: ow-0388

Since DARTIS annotations are 640x640 sub-chips and their precise pixel-mapping lacks sub-pixel geotransforms in the metadata, we preserve the published annotation as a reference object rather than fabricating an inexact spatial mask. This ensures scientific integrity.
